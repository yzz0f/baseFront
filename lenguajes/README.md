# Módulos de lenguaje

Cada carpeta es un módulo con `GUIA.md`, `reglas.mdc` y `check.sh`. Se crean con `./scripts/agregar-lenguaje.sh <nombre>` y los completan las personas que trabajan con ese lenguaje (ver [docs/06-agregar-un-lenguaje.md](../docs/06-agregar-un-lenguaje.md)).

`_plantilla/` es el punto de partida y no se ejecuta.
